# Build Securely. Grow Strategically.

## Make your GitHub profile show what you can do next

Choose a direction, show work that supports it and give another person enough context to evaluate your contribution. This workshop turns a GitHub profile into a starting point for a useful career conversation.

**Workshop co-presenters:** Santos Martinez and Victoria Entz.

Santos connects technical work to visible evidence. Victoria's career-development perspective connects that evidence to transferable skills, a next-role direction and a conversation with a mentor. The exercises here are original workshop guidance, not quotations or transcripts.

## Start here

1. [Complete the profile lab](docs/PROFILE-LAB.md). Fork this repository, clone your fork and create your own profile README.
2. [Use the USF example](docs/USF-CASE-STUDY.md). Explain one contribution you actually made and separate demonstrated work from future plans.
3. [Check your career strategy](docs/CAREER-STRATEGY.md). Connect one existing strength to one next-role skill.
4. [Credit your sources](docs/CITATIONS.md). Cite the original project, preserve its license and disclose AI assistance when applicable.
5. [Review before publishing](docs/REVIEW-CHECKLIST.md). Check evidence, permissions, public links and attribution.

No Azure subscription, API key or code execution is needed for the profile lab. Building or running the separate USF extension is optional and has different prerequisites and safety requirements.

## What you will produce

| Deliverable | What a reader should learn |
| --- | --- |
| A short profile introduction | Your current focus and the direction you are exploring |
| One evidence-linked project story | The problem, your contribution, what you checked and the limits |
| A curated set of pinned repositories | Where to inspect the work behind your claims |
| A citation and attribution record | Who created the original work and what you changed |
| A specific feedback request | Which decision, explanation or skill you want help improving |

Suggested format: spend 20-30 minutes on the lab, then exchange feedback with a partner. This timing is a facilitation suggestion, not a prerequisite or completion credential.

## Fork, clone and profile: three different things

A **fork** is your GitHub-hosted copy of this workshop. A **clone** is a local copy on your computer. A **profile repository** is a separate public repository named exactly like your GitHub username, with a nonempty `README.md` at its root. Forking this workshop alone does not create a profile README. (GitHub, n.d.-a, n.d.-b)

Use your own fork for your personal exercise. Open a pull request to this upstream repository only to improve the shared instructions, not to submit personal career information.
