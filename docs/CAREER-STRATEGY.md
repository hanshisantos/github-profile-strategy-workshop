# Connect your profile to a next-role conversation

## Start with an existing strength

Name a problem you already understand. Then choose one adjacent skill that would let you tackle a more demanding version of that problem.

This exercise connects technical evidence to the career-development perspective Victoria Entz brings as workshop co-presenter. It is original facilitation guidance, not a quoted framework or a claim that Victoria authored the USF code.

## Example: technical work that supports a transition

Suppose you already explain technical concepts well and want to explore secure AI application development. Use the USF lab to create a readable trust-boundary diagram and a documented design decision.

Communication is your transferable strength. Security design is the skill you are developing. The diagram and decision record let someone evaluate both without taking your profile claims on trust.

This is a suggested pathway. It does not imply that completing a workshop qualifies you for a job or proves production security competence.

## Write a useful introduction

> I work on [problem or field]. My current projects explore [direction], and [linked artifact] shows how I approached [specific decision]. I would value feedback on [bounded question].

You can be early in the journey. Say what you are learning and let the evidence carry the claim.

Avoid broad labels such as "expert" unless you have the experience to support them. Do not list certifications you intend to earn as credentials you already hold.

## Ask for feedback that can change the work

Try one question:

- "Can you tell what I personally contributed?"
- "Does this project support the direction I say I am exploring?"
- "Which design decision needs a clearer explanation?"
- "What evidence would you need before trusting this claim?"

Do not publish a mentor's name, quotation or private feedback without permission. Keep your personal career worksheet local if you prefer.

## Set a 30-day practice

Choose one artifact to improve, one place to share it and one person or community to ask for feedback. Put a date on the next action.

Return to your profile after that action. Add the evidence you produced, revise any claim it does not support and remove links that no longer help the reader.
